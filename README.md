# XLPlain — GitHub Pages

Сайт XLPlain опубликован по адресу:

https://aykhanov.github.io/xlplain/

XLPlain — надстройка для Microsoft Excel / Windows для сверки и объединения таблиц, очистки данных, поиска дублей, создания сводных таблиц и дашбордов, а также работы с папками и файлами.

## Текущий статус

- сайт опубликован и работает в боевом режиме;
- покупка через Robokassa активна;
- контрольная реальная покупка и полная цепочка выдачи лицензии проверены;
- лицензия выдаётся автоматически после успешной оплаты;
- основной тип коммерческой лицензии — годовая;

- для поисковой индексации используются `robots.txt` и `sitemap.xml`.

## Платёжная схема

Форма покупки отправляет POST-запрос на Yandex Cloud Function:

`https://functions.yandexcloud.net/d4eqf3vcn7fdkg0f5td4`

Основные поля формы:

- `action=create_payment`;
- `email=<email покупателя>`.

Сервер формирует платёж Robokassa и перенаправляет покупателя на страницу оплаты.

После подтверждения успешной оплаты серверная часть обрабатывает платёж, создаёт лицензию и отправляет покупателю письмо с лицензионным ключом и дальнейшими инструкциями.

- стоимость новой лицензии — 3 990 ₽;
- стоимость продления определяется по цене, действующей на дату продления.

Для работы с таблицами интернет не используется: данные обрабатываются локально в Excel. Интернет требуется для активации и периодической проверки лицензии.
