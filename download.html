Как установить

  1. Скачайте и распакуйте архив XLPlain_v1.0.zip в постоянную папку на компьютере.
  2. Не запускайте надстройку прямо из ZIP-архива.
  3. Если Windows заблокировал файл: нажмите правой кнопкой мыши на XLPlain_v1.0.xlam → «Свойства» → включите «Разблокировать», если такой пункт есть → «Применить».
  4. Откройте Microsoft Excel.
  5. Перейдите: Файл → Параметры → Надстройки.
  6. Внизу окна выберите: Управление: Надстройки Excel → Перейти.
  7. Нажмите «Обзор», выберите XLPlain_v1.0.xlam и подтвердите подключение.
  8. После установки в Excel появится вкладка XLPlain.

Как активировать

  1. Откройте любой инструмент XLPlain.
  2. Введите лицензионный ключ из письма после покупки.
  3. Для первой активации требуется подключение к интернету.
  4. Один ключ можно использовать максимум на двух одновременно активных компьютерах.
  5. После окончания периода возврата XLPlain выполнит финальную онлайн-проверку. После неё бессрочная лицензия работает без постоянного подключения к серверу.

Перенос лицензии

Чтобы освободить место для другого компьютера, на вкладке XLPlain используйте кнопку «Перенести лицензию». После освобождения текущего компьютера тот же ключ можно активировать на другом устройстве при наличии свободного слота.
