Объединение таблиц Excel

Как объединить две таблицы Excel по общему столбцу

Если в двух таблицах есть общий идентификатор — например ID, артикул, номер договора или код клиента — строки можно сопоставить по этому ключу и собрать нужные поля в одну итоговую таблицу.

ПошаговоОбъединение в XLPlain

Что значит объединить таблицы по общему столбцу

Это не добавление строк одной таблицы под другую. Здесь задача другая: найти одну и ту же запись в двух наборах данных и дополнить её информацией из второй таблицы.

По ID

В первой таблице есть ID клиента и сумма заказа, во второй — тот же ID и контактные данные. После объединения нужные поля оказываются в одной строке.

По артикулу

Можно связать прайс-лист и остатки по артикулу, если этот столбец одинаково идентифицирует товар в обеих таблицах.

По нескольким полям

Если одного столбца недостаточно, ключ можно составить из нескольких полей — например номер документа + дата.

Как объединить две таблицы по ключу

1. Найдите общий ключВыберите поле, которое однозначно связывает записи: ID, артикул, номер документа или другую устойчивую комбинацию.
2. Проверьте значения ключаФормат должен совпадать по смыслу: лишние пробелы, разные типы данных или неодинаковая запись кода могут мешать сопоставлению.
3. Определите, какие поля нужно подтянутьНе обязательно переносить всю вторую таблицу. Выберите только нужные столбцы результата.
4. Выполните сопоставлениеВ Excel это можно сделать формулами поиска или Power Query. Для повторяемых задач удобнее использовать отдельный инструмент объединения.
5. Проверьте строки без соответствийЕсли часть ключей найдена только в одной таблице, отдельно проверьте, является ли это нормальной ситуацией или ошибкой данных.

Чем это отличается от ВПР

Логика похожа: по ключу находится связанная запись и из неё подтягивается нужное значение. Но когда нужно переносить много полей, использовать несколько таблиц или составной ключ, большое количество отдельных формул становится неудобным.

Важно: если задача — просто собрать однотипные строки из многих файлов друг под другом, это другой сценарий. Для него в XLPlain используется модуль «Папки и файлы».

Как объединить таблицы в XLPlain

Модуль «Объединение таблиц» работает с 2–6 таблицами и сопоставляет записи по одному или составному ключу.

Выбор ключей

Для каждой таблицы можно определить одно или несколько ключевых полей.

Поля результата

Вы выбираете, какие данные из каждой таблицы должны попасть в итоговый набор.

Значения формул

При сопоставлении используются вычисленные значения ячеек, поэтому ключи и переносимые данные могут быть получены формулами.

Частые вопросы

Можно ли объединить таблицы по столбцам с разными названиями?

Да. Важен смысл ключевого поля, а не одинаковое название заголовка. При настройке нужно указать, какие поля соответствуют друг другу.

Что делать, если одного общего столбца недостаточно?

Используйте составной ключ из нескольких полей, если именно их комбинация однозначно определяет запись.

Можно ли объединить больше двух таблиц?

Да. В XLPlain в одном сценарии можно использовать от 2 до 6 таблиц.

Это объединение файлов друг под другом?

Нет. Здесь записи связываются по ключу. Сбор однотипных данных из нескольких файлов — отдельный сценарий «Папки и файлы».
