Как сделать сводную таблицу из нескольких файлов Excel

Если отчёты хранятся в нескольких книгах Excel, удобнее сначала собрать однотипные данные в один массив, а уже потом строить по нему сводную таблицу и дашборд.

ПошаговоСводные в XLPlain

Почему сводную лучше строить по единому массиву

Одинаковая структура

Если каждый файл содержит одинаковые столбцы — например, дата, клиент, товар и сумма — данные можно собрать друг под другом в одну таблицу.

Проще обновлять

Один источник удобнее контролировать, фильтровать и использовать для повторяемой аналитики.

Меньше ручной работы

Не нужно строить отдельную сводную по каждой книге и затем вручную сводить результаты.

Как сделать сводную из нескольких Excel-файлов

1. Проверьте структуру файловЗаголовки и смысл столбцов должны совпадать. Если в одном файле поле называется «Сумма», а в другом «Выручка», сначала приведите структуру к понятному виду.
2. Соберите таблицы в один массивДобавьте строки из всех однотипных файлов в одну итоговую таблицу. Для этого можно использовать Power Query или модуль XLPlain «Папки и файлы».
3. Проверьте типы данныхУбедитесь, что даты распознаны как даты, числа — как числа, а внутри массива нет лишних пустых строк.
4. Создайте сводную таблицуИспользуйте объединённый массив как единый источник и распределите поля по строкам, столбцам, значениям и фильтрам.
5. При необходимости добавьте дашбордНа основе сводной можно создать KPI, графики, срезы и временную шкалу.

Как это сделать в XLPlain

В XLPlain эта задача состоит из двух последовательных сценариев.

Шаг 1. «Папки и файлы»

Соберите таблицы из нескольких Excel-файлов в одну итоговую таблицу. Этот сценарий предназначен именно для однотипных данных из разных книг.

Шаг 2. «Сводные и дашборды»

По готовому массиву создайте сводную таблицу и при необходимости дашборд с KPI, графиками, срезами и таймлайном.

Важно: XLPlain не строит сводную напрямую по набору разрозненных файлов одной кнопкой. Сначала данные объединяются в единый массив, затем по нему создаётся аналитика.

Когда этот способ особенно удобен

Ежемесячные отчёты

Когда каждый месяц создаётся отдельный Excel-файл одинаковой структуры.

Файлы по филиалам

Когда подразделения присылают однотипные выгрузки, которые нужно анализировать вместе.

Регулярная управленческая аналитика

Когда новые файлы появляются постоянно, а итоговый отчёт должен сохранять одну и ту же структуру.

Частые вопросы

Можно ли сделать одну сводную таблицу из нескольких Excel-файлов?

Да. Удобный вариант — сначала объединить однотипные данные из файлов в один массив, а затем использовать его как источник сводной таблицы.

Нужно ли, чтобы во всех файлах были одинаковые столбцы?

Для простого объединения лучше использовать одинаковую структуру и одинаковый смысл полей. Это уменьшает количество ручной подготовки перед аналитикой.

Можно ли сохранить настройки сводной в XLPlain?

Да. Для функции «Сводные и дашборды» настройки можно сохранить в профиль и использовать повторно.

Файлы загружаются в интернет?

Нет. Рабочие Excel-файлы обрабатываются локально на компьютере пользователя.
