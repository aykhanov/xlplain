Сверка реестров Excel

Как сверить два реестра Excel по ID или номеру документа

Два реестра лучше сопоставлять по устойчивому идентификатору: ID, номеру документа, договору или комбинации нескольких полей. Тогда порядок строк не влияет на результат.

Какие расхождения ищут при сверке

Изменённые записи

Ключ присутствует в обоих реестрах, но одно или несколько значений изменились.

Добавленные записи

Запись появилась только в новом реестре.

Отсутствующие записи

Запись осталась только в старом реестре и отсутствует в новом.

Как сверить два реестра

1. Выберите ключID или номер документа должен однозначно связывать одинаковую запись в двух файлах.
2. Используйте составной ключ при необходимостиЕсли одного поля недостаточно, используйте комбинацию нескольких признаков.
3. Сопоставьте сравниваемые поляОпределите, какие колонки нужно сравнить, даже если их названия в файлах различаются.
4. Разделите результат по типам измененийОтдельно анализируйте неизменённые, изменённые, добавленные и удалённые записи.

Сверка реестров в XLPlain

XLPlain выполняет сверку по ключевым полям, а не по позиции строки. Настройки можно сохранить в профиль для повторной работы с реестрами той же структуры.

Разные названия колонок

Нужные поля можно явно сопоставить между двумя файлами.

Формулы

При сравнении используются вычисленные значения ячеек.

Профиль

Настройки сверки можно сохранить и загрузить при следующем запуске.

Частые вопросы

Можно ли сверять реестры, если строки расположены по-разному?

Да. При сверке по ключу порядок строк не имеет значения.

Можно ли сверять по нескольким полям?

Да. Для этого используется составной ключ.

Можно ли сохранить настройки?

Да. Для сверки данных в XLPlain предусмотрены профили.
