Сравнение таблиц Excel

Как сравнить две таблицы Excel и найти различия

Если есть две версии реестра, выгрузки, отчёта или справочника, их можно сравнить по одному или нескольким ключевым полям и отдельно увидеть совпадения, изменения, новые и отсутствующие записи.

Как сравнить таблицыСравнение в XLPlain

Рабочие Excel-файлы обрабатываются локально на компьютере. Содержимое таблиц не передаётся во внешние сервисы и не используется ИИ.

Когда нужно сравнить две таблицы Excel

Такая задача возникает при проверке версии «до» и «после», сверке выгрузок из разных систем, обновлённых справочников, прайс-листов, реестров и отчётов. Если строк много, простое построчное сравнение быстро становится неудобным.

Совпадения

Нужно определить записи, которые присутствуют в обеих таблицах и совпадают по выбранным полям.

Различия

Нужно увидеть, какие значения изменились у одной и той же записи — например, цена, статус, сумма или ответственное лицо.

Добавленные и удалённые строки

Важно отдельно выделить записи, которые появились только в новой таблице или остались только в старой.

Как сравнить две таблицы Excel на совпадения и различия

Главное — не сравнивать строки только по их номеру. Сначала нужно определить, по какому признаку одна запись соответствует другой.

1. Определите ключ сравненияЭто может быть ID, артикул, номер документа или комбинация нескольких полей. Ключ должен позволять однозначно сопоставить запись из первой таблицы с записью из второй.
2. Сопоставьте столбцыЕсли таблицы имеют разную структуру или разные названия колонок, определите, какие поля нужно сравнивать между собой.
3. Найдите совпадающие записиПосле сопоставления по ключу можно отделить строки, которые присутствуют в обеих таблицах.
4. Проверьте измененияДля совпавших ключей сравните нужные поля и отметьте значения, которые изменились.
5. Отдельно покажите добавленные и удалённые записиКлючи, найденные только в новой таблице, считаются добавленными, а оставшиеся только в старой — удалёнными.

Какими способами можно сравнить таблицы в Excel

Для разовой небольшой задачи можно использовать стандартные инструменты Excel. При регулярной сверке удобнее автоматизировать сам сценарий сравнения.

Формулы поиска и ВПР

Подходят, когда нужно найти соответствие по одному ключу и подтянуть значение из второй таблицы. Для большого количества проверяемых полей формулы быстро усложняются.

Условное форматирование

Полезно для визуального выделения совпадений или отличающихся значений, когда структура таблиц уже сопоставима.

Power Query

Подходит для подготовки повторяемых сценариев преобразования и сопоставления данных, если пользователь готов настроить запрос.

Сравнение таблиц на разных листах и в разных файлах

Принцип остаётся тем же: место хранения таблицы не меняет логику сравнения. Важно определить ключ и соответствия полей. Поэтому можно сравнивать данные на разных листах или в двух отдельных Excel-файлах, если структура позволяет сопоставить записи.

Если сравнение выполняется регулярно: лучше использовать одинаковую структуру файлов и стабильные ключевые поля. Это снижает количество ручной настройки при каждой новой проверке.

Как сравнить два файла Excel в XLPlain

XLPlain автоматизирует сценарий сравнения двух файлов. Для регулярной работы с двумя папками и пакетной проверки используйте страницу «Сверка данных в Excel».

Выберите два файла и нужные листыУкажите старую и новую таблицу, которые нужно сравнить.
Задайте ключевые поля и соответствияВыберите одно или несколько полей, по которым сопоставляются записи, и при необходимости свяжите колонки с разными названиями.
Запустите сверкуXLPlain формирует результат с категориями «без изменений», «изменено», «добавлено» и «удалено» и показывает старое и новое значения для изменённых полей.

Демонстрация: сверка двух файлов Excel.

Ключевое отличие: сравнение выполняется локально в Excel. Рабочие файлы не нужно загружать на сайт или передавать стороннему онлайн-сервису.

Нужно сравнивать таблицы регулярно?

Настройки сверки можно сохранить в профиль и использовать повторно. Для пакетной проверки файлов в двух папках в XLPlain предусмотрен отдельный сценарий сверки.

Частые вопросы

Как сравнить две таблицы в Excel на совпадения?

Определите ключевое поле, по которому записи соответствуют друг другу, затем сопоставьте ключи двух таблиц. После этого можно отдельно проверить значения остальных столбцов.

Как сравнить две таблицы Excel на различия?

После сопоставления записей по ключу сравните нужные поля у одинаковых ключей. Отдельно выделите изменённые значения и записи, которые присутствуют только в одной из таблиц.

Можно ли сравнить таблицы на разных листах Excel?

Да. Если записи можно сопоставить по ключу, таблицы могут находиться на разных листах. Тот же принцип применяется и к двум отдельным файлам.

Можно ли сравнить таблицы с помощью ВПР?

Да, ВПР может использоваться для поиска соответствий по ключу в простой задаче. Если нужно проверить много полей, разделить добавленные, удалённые и изменённые записи, ручная схема из формул становится более объёмной.

Можно ли сравнивать по нескольким столбцам?

Да. В XLPlain комбинация нескольких полей может использоваться как составной ключ.

Можно ли сохранить настройки сравнения?

Да. Настройки сверки можно сохранить как профиль и загрузить при следующем сравнении файлов с аналогичной структурой. Для пакетной сверки также предусмотрены профили.

Нужно ли загружать файлы на сайт?

Нет. Обработка выполняется локально в Excel на компьютере пользователя.
