# Тренажёр Excel · SQL · Power BI

Исходники тренажёра. Готовая сборка кладётся в `../trenazher-beta/` (тестовый контур) или `../trenazher/` (боевой).

## Как добавить задачу

1. Скопируйте похожий файл в `content/excel`, `content/sql` или `content/bi` и поменяйте поля.
2. `npm run check` — сборка проверит каждую задачу: эталон решается, подмена числом не проходит,
   SQL-эталон работает на обеих базах, у кейса Power BI посчитан ответ. Ошибка в задаче — сборка не выходит.
3. Поле `verified` заполняется после ручной проверки в настоящем Excel, базе или Power BI.

## Команды

- `BETA=1 npm run build` — тестовый контур `/trenazher-beta/` (noindex, без Метрики)
- `BETA=0 npm run build` — боевая сборка `/trenazher/` (делается только при выкатке)
- `npm test` — проверки задач и движков

## Учебная база

`scripts/dataset.mjs` — генератор базы «компания». seed 1 — открытая база, seed 2 — проверочная.
Из открытой базы собирается датасет Power BI `public/data/prodazhi.csv`.
