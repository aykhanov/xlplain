Развернуть месяцы в строки

План продаж сделан в Excel «в ширину»: менеджеры по строкам, месяцы по столбцам. Для Power BI нужна длинная таблица, иначе не построить ни срез по месяцам, ни сравнение с фактом.

Получите таблицу из трёх столбцов: Менеджер (текст), Месяц (текст), План (десятичное число). Пустые ячейки плана в результат не попадают.
