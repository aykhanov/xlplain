Порядок шагов очистки выгрузки

Выгрузка из 1С: сверху три строки шапки отчёта, потом заголовки столбцов, внизу строка «Итого», а между блоками пустые строки.

Расставьте шаги Power Query в правильном порядке
  1. Удалить пустые строки
  2. Отфильтровать строку «Итого»
  3. Использовать первую строку в качестве заголовков
  4. Удалить первые 3 строки
  5. Изменить тип столбца «Дата» на дату

Заголовки можно повысить, только когда они оказались первой строкой. Тип «Дата» ставьте последним, когда в столбце остались одни даты.

Формулы DAX приведены с разделителем «;», как в русском Excel. Если в вашем Power BI аргументы разделяются запятой, замените «;» на «,». Нашли ошибку? Напишите нам.
