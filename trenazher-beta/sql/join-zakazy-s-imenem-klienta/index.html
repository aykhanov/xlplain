Заказы октября с именем клиента

В таблице orders вместо имени клиента стоит только его номер client_id. Бухгалтерии нужен понятный список.

Выведите номер заказа, дату и имя клиента для заказов с 1 по 31 октября 2026 года

JOIN … ON c.id = o.client_id находит для каждого заказа клиента с тем же номером. Даты здесь хранятся текстом в формате ГГГГ-ММ-ДД, поэтому BETWEEN работает.
Решение:
SELECT o.id, o.order_date, c.name
FROM orders o
JOIN clients c ON c.id = o.client_id
WHERE o.order_date BETWEEN '2026-10-01' AND '2026-10-31';

Запросы выполняются в SQLite прямо в браузере. Синтаксис почти везде как в SQL Server и PostgreSQL, отличия отмечены в лайфхаках. Нашли ошибку? Напишите нам.
